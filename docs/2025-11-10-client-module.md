# 客户管理模块需求文档

**创建时间**：2025-11-10  
**需求来源**：用户需求  
**状态**：开发中

## 需求背景

为了更好地管理客户相关的业务数据和操作，需要构建一个独立的客户管理模块。该模块应具有独立的左侧导航菜单，方便用户在不同客户的各项业务功能间快速切换。

## 功能需求

### 1. 模块入口

- **首页入口**：在首页"我服务的客户"卡片中，点击任一客户卡片进入该客户的管理模块
- **客户列表入口**：在全部客户列表页面，点击客户条目进入该客户的管理模块
- **路由设计**：`/clients/:clientId/*`

### 2. 页面布局

- **顶部导航栏**：保留系统全局顶部导航栏（首页、魔盒 MagiCore、知识库等）
- **左侧菜单**：客户模块专属侧边栏菜单，包含：
  - **菜单首行**：客户切换器（下拉选择框），支持快速切换到其他客户
  - **功能菜单**：
    - 总览
    - 活动管理
    - 数据交付
    - 文件交付
    - 数据资产
    - 客户管理
- **内容区域**：右侧主内容区，展示当前选中菜单对应的页面

### 3. 菜单功能说明

#### 3.1 客户切换器（菜单首行）

- 展示当前查看的客户名称
- 支持下拉选择，快速切换到其他客户
- 切换后自动刷新当前页面内容（保持在同一菜单项）

#### 3.2 总览

- **功能**：展示客户的基本信息、业务概览、关键指标
- **状态**：已实现（当前的客户详情页）
- **页面结构**：
  - 基本信息卡片：客户名称、版本号、运营模式、运营人员
  - 极简任务列表：显示待办任务及其状态
  - 经营推荐方案：展示针对该客户的推荐方案
  - 能力推荐：推荐适用的系统能力
  - 昨日关键数据：展示日活、新增用户、人均时长、留存率等关键指标及趋势图表

#### 3.3 活动管理

- **功能**：管理该客户的营销活动
- **状态**：跳转到现有的活动管理页面
- **路由**：点击后跳转至 `/activity-management`（需传递客户上下文）

#### 3.4 数据交付

- **功能**：管理该客户的数据交付任务
- **状态**：待设计
- **预期内容**：
  - 数据交付任务列表
  - 任务状态跟踪
  - 数据源配置
  - 交付记录查询

#### 3.5 文件交付

- **功能**：管理该客户的文件交付
- **状态**：待设计
- **预期内容**：
  - 文件交付任务列表
  - 文件上传/下载
  - 交付进度跟踪
  - 历史记录

#### 3.6 数据资产

- **功能**：展示和管理该客户的数据资产
- **状态**：待设计
- **预期内容**：
  - 数据资产目录
  - 数据质量报告
  - 数据使用情况统计
  - 数据血缘关系

#### 3.7 客户管理

- **功能**：管理客户的基础信息和配置
- **状态**：待设计
- **预期内容**：
  - 客户基本信息编辑
  - 联系人管理
  - 业务配置
  - 权限设置

## 技术实现

### 路由设计

```
/clients/:clientId/overview       - 总览
/clients/:clientId/activities     - 活动管理（或跳转到 /activity-management?clientId=xxx）
/clients/:clientId/data-delivery  - 数据交付
/clients/:clientId/file-delivery  - 文件交付
/clients/:clientId/data-assets    - 数据资产
/clients/:clientId/settings       - 客户管理
```

### 组件结构

```
src/
  layouts/
    client-module-layout.tsx      - 客户模块布局（包含左侧菜单）
    client-module-layout.module.css
  pages/
    clients/
      client-module/
        overview/                 - 总览（复用现有详情页）
        data-delivery/            - 数据交付
        file-delivery/            - 文件交付
        data-assets/              - 数据资产
        settings/                 - 客户管理
      components/
        client-switcher.tsx       - 客户切换器组件
```

### 状态管理

- 使用 URL 参数 `clientId` 标识当前客户
- 左侧菜单根据 `clientId` 动态生成路由链接
- 客户切换器从全局客户列表获取数据

## UI/UX 设计要点

1. **左侧菜单**：
   - 宽度固定（如 200px）
   - 客户切换器置顶，带下拉图标
   - 菜单项高亮当前选中项
   - 支持折叠（可选）

2. **客户切换器**：
   - 显示客户 Logo（如有）+ 客户名称
   - 下拉列表展示所有可访问客户
   - 支持搜索过滤（客户数量较多时）

3. **内容区域**：
   - 自适应宽度
   - 保持与系统其他页面一致的样式风格
