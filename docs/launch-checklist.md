# 交付中台前端 — 项目上线自检清单

> 基于当前仓库：`React 19` + `Vite 7` + `TypeScript` + `Ant Design 5` + `React Router 7` + `Redux Toolkit`。  
> 适用场景：静态资源部署（Nginx / OSS+CDN / 对象存储等）与联调验收。

使用前请按环境（测试 / 预发 / 生产）勾选，并记录负责人与日期。

---

## 一、构建与产物

| 序号 | 检查项 | 说明 / 当前项目注意点 | 通过 |
|------|--------|------------------------|------|
| 1.1 | 本地可完整构建 | 执行 `npm run build`（含 `tsc -b` + `vite build`），无报错 | ☐ |
| 1.2 | 产物体积与分包 | 查看 `dist/assets`，异常大文件是否需懒加载或拆包 | ☐ |
| 1.3 | Source Map 策略 | 生产是否关闭或仅内网可访问，避免源码泄露 | ☐ |
| 1.4 | 构建环境与锁文件 | 使用与 CI 一致的 Node 版本；优先 `npm ci` 锁定依赖 | ☐ |

---

## 二、路由与静态托管（SPA）

| 序号 | 检查项 | 说明 / 当前项目注意点 | 通过 |
|------|--------|------------------------|------|
| 2.1 | History 路由回退 | 非根路径刷新（如 `/home`、`/clients/xxx`）需服务端 **fallback 到 `index.html`** | ☐ |
| 2.2 | `base` 路径 | 若部署在子路径（如 `/app/`），需在 `vite.config.ts` 配置 `base`，并验证资源路径 | ☐ |
| 2.3 | 404 / 403 页 | 非法路径、无权限是否有明确提示（当前以路由与 `ProtectedRoute` 为主） | ☐ |

## 三、环境与配置

| 序号 | 检查项 | 说明 / 当前项目注意点 | 通过 |
|------|--------|------------------------|------|
| 3.1 | API 基地址 | `src/api/http.ts` 当前 `baseURL: '/'`；接真实后端时需按环境切换（建议 `import.meta.env` + `.env.*`） | ☐ |
| 3.2 | 超时与错误处理 | Axios `timeout`、拦截器错误提示是否在联调环境可接受 | ☐ |
| 3.3 | 外部链接 | 魔盒 / 导航中 **即时零售运营 AI Agent** 指向 `https://agent-helper.netlify.app/`：生产网络是否可访问、是否需换正式域名 | ☐ |
| 3.4 | 功能开关 | 未完成模块是否在非生产环境隐藏或标注「演示」 | ☐ |

## 四、鉴权与安全

| 序号 | 检查项 | 说明 / 当前项目注意点 | 通过 |
|------|--------|------------------------|------|
| 4.1 | 登录态实现 | 当前为 **模拟登录**（`AuthService` + `localStorage`）；上线前需替换为真实登录、Token 刷新与过期策略 | ☐ |
| 4.2 | Token 存储 | 评估 `localStorage` vs `httpOnly` Cookie；XSS 风险与退出登录清理 | ☐ |
| 4.3 | 受保护路由 | `ProtectedRoute` 未登录跳转 `/login`；验证所有业务路由均已包裹 | ☐ |
| 4.4 | 敏感信息 | 构建产物、仓库、控制台日志中无密钥、内网地址、测试账号明文 | ☐ |
| 4.5 | `rel` 与 `target` | 外链新标签页已使用 `rel="noreferrer"` 等（按页面逐项确认） | ☐ |

> 根据版本范围勾选；全量回归前至少覆盖主路径。

| 模块 | 路由示例 | 检查要点 | 通过 |
